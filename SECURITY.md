# Security Policy

## Supported Versions

Only the latest [release](https://github.com/projectbluefin/bluefin-report/releases),
installed through the Homebrew cask, is supported.

## Reporting a Vulnerability

Bluefin Report handles system data and publishes it with your `gh` login, so a flaw in
its privacy scrubbing or publishing is high-impact.

**Please do not report security vulnerabilities through public GitHub issues.**
Use GitHub's **Private Vulnerability Reporting**:

<https://github.com/projectbluefin/bluefin-report/security>

Include the affected version, steps to reproduce, and your assessment of the impact.
We will acknowledge the report, keep you informed, and credit you unless you ask otherwise.
